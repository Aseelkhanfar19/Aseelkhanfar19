## 🛠️ How I Like to Build

I prefer understanding the "why" behind the code rather than
just making something work.

I enjoy breaking problems down, understanding how different
parts of a system communicate, and gradually turning those
ideas into working software.

I'm especially interested in the parts that happen behind the UI:
APIs, databases, authentication, business logic, data processing,
and the systems that connect everything together.

I also like thinking beyond the expected flow — testing edge cases, considering how a system behaves when things go wrong, and making sure the logic handles unexpected inputs and situations.
